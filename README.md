# دليل الضمير التعليمي

واجهة عربية لمنصة المعلمين والمعلمات، الدورات والدروس الخصوصية، المدارس، وبطاقات المعلمين الذين تركوا أثرًا.

## تشغيل النسخة الحالية

يمكن فتح `index.html` مباشرة في المتصفح. أو تشغيل خادم محلي من مجلد المشروع:

```powershell
node -e "require('http').createServer((q,s)=>{const fs=require('fs'),p=require('path');let f=p.join(process.cwd(),decodeURIComponent(q.url.split('?')[0]));if(q.url==='/')f=p.join(process.cwd(),'index.html');fs.readFile(f,(e,d)=>{if(e){s.writeHead(404);s.end('Not found');return}s.setHeader('Content-Type',f.endsWith('.css')?'text/css':f.endsWith('.js')?'text/javascript':'text/html; charset=utf-8');s.end(d)})}).listen(4173,'127.0.0.1')"
```

ثم افتح `http://127.0.0.1:4173`.

## حالة النسخة

- الموقع يقرأ الدليل المنشور والخيارات من Supabase، ويرسل طلبات المعلمين والبطاقات التذكارية عبر RPC آمن. رمز المعلم يُخزن في قاعدة البيانات كتجزئة bcrypt. الصور الشخصية والتذكارية وصور الإعلانات والمدارس تُرفع كملفات إلى bucket `dameer-media`، وتحفظ قاعدة البيانات رابط الصورة فقط. صور شرائح الصفحة الرئيسية تستخدم المجلد `slides` ورابط `homepage_slides.image_url` عند تفعيل إدارة الشرائح.
- تسجيل دخول الإدارة ومراجعة الطلبات مرتبطان بحسابات Supabase Auth المضافة إلى قائمة مديري المنصة. عمليات إعلانات المعلمين تتم عبر RPCs تتحقق من رمز التحكم ذي 8 أرقام.
- شغّل `schema.sql` مرة واحدة ثم `supabase-link.sql` و`supabase-admin.sql` و`supabase-storage.sql` من SQL Editor. شغّل أيضًا `supabase-schools-images.sql` لإضافة صور المدارس وإجراءات الإضافة والتعديل والحذف. يمكن إعادة تشغيل هذا الترحيل عند تحديث وظائفه. حدّد محتوى كل ملف كاملًا قبل تشغيله. ترحيل التخزين ينشئ bucket صور عامة بحد 2 ميغابايت للصورة، ويسمح بمجلدات `profiles` و`memorials` و`listings` و`slides` و`schools`. يضغط الموقع الصور تلقائيًا إلى JPEG، ويقلص أبعادها إلى 1200 بكسل كحد أقصى، ويستهدف نحو 450 كيلوبايت قبل الرفع.
- مفتاح `anon` المضمّن مخصص للواجهة العامة. لا تضف مفتاح `service_role` إلى ملفات الواجهة أو المستودع؛ فقد شاركته في المحادثة، لذا يُنصح بتدويره من إعدادات Supabase.

## الملفات

- `index.html`: الدليل العام والبحث والتنقل بين أقسامه.
- `apply.html`: تقديم طلب بطاقة معلم أو بطاقة تذكارية.
- `manage.html`: إدارة المعلم لبطاقته وإعلاناته.
- `admin.html`: لوحة الإدارة ومراجعة الطلبات وإدارة المدارس والسلايدر.
- `styles.css`: التصميم المتجاوب واتجاه RTL.
- `app.js`: الواجهة والتفاعلات والنماذج، مع تحميل البيانات العامة من Supabase فقط.
- `supabase-config.js`: رابط المشروع ومفتاح `anon` العام.
- `supabase-link.sql`: سياسات الوصول ووظائف استقبال الطلبات.
- `schema.sql`: مخطط قاعدة بيانات PostgreSQL الأولي.
## إبراز البطاقات في الصفحة الرئيسية

إعداد الحقول ووظائف الإدارة محفوظ في `supabase-featured.sql`. يُشغّل بعد `schema.sql` و`supabase-link.sql` و`supabase-admin.sql`. التطبيق يقرأ `home_featured` و`home_badge_text` للمعلمين والإعلانات والبطاقات التذكارية، ويحفظ اختيار الإدارة عبر دالة RPC ذات صلاحية إدارية. يحتوي الملف أيضاً على إصدار رمز تحكم جديد من الإدارة والتحقق الآمن من رمز المعلم؛ الرمز الصريح يظهر مرة واحدة للمدير بينما تحفظ قاعدة البيانات تجزئته فقط.

لدعم تعدد مواد الإعلان وتاريخ بدء الدورة في Supabase، شغّل `supabase-listing-updates.sql` مرة واحدة. هذا الترحيل ينقل مادة الإعلانات الحالية إلى جدول المواد المتعددة ويحفظ تاريخ بدء الدورة اختيارياً. شغّل `supabase-teacher-listings-rpc.sql` لربط إنشاء الإعلانات وتعديلها وحذفها وإعادة نشرها بقاعدة البيانات، مع تحقق الخادم من رمز المعلم.
